# 🔒 Trilha de Cibersegurança

Uma plataforma web interativa, moderna e estruturada para guiar estudantes e iniciantes do zero até a profissionalização em Segurança da Informação (com foco em Fundamentos, Redes, Análise Defensiva / Blue Team, Operações Ofensivas / Red Team, Governança e Carreira).

## ✨ Funcionalidades Principais

- **Trilha Completa e Organizada:** Dividida em módulos estratégicos cobrindo desde Sistemas Operacionais e Redes até SOC, Pentest e LGPD.
- **Checklist de Progresso Interativo:** Marque os tópicos conforme for estudando. O avanço é salvo automaticamente no seu navegador (`localStorage`).
- **Bloco de Anotações por Módulo:** Um espaço dedicado em cada cartão para registrar comandos do terminal, resumos ou links importantes de forma individual.
- **Recursos & Ferramentas Recomendadas:** Atalhos diretos para portais de referência, documentações oficiais e laboratórios (com forte curadoria de fontes de autoridade brasileiras e globais).
- **Temas Cibernéticos Personalizáveis:** Alternância dinâmica entre paletas visuais (Ciano Cibernético, Matrix e Roxo Neon) sobre um fundo animado com efeito de chuva digital.
- **Backup de Dados (Exportar/Importar):** Sistema prático para exportar seu progresso e anotações em formato JSON, garantindo que você nunca perca seu histórico.
- **Certificado Virtual de Conclusão:** Ao atingir 100% de aproveitamento na trilha, a plataforma desbloqueia um certificado personalizado para coroar seus estudos.

## 🚀 Tecnologias Utilizadas

- **HTML5** (Estrutura limpa e semântica)
- **CSS3** (Design System com variáveis, Glassmorphism e responsividade)
- **JavaScript (Vanilla)** (Persistência de dados, animação em Canvas e interatividade)
